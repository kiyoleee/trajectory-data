## Output contract

Write exactly one JSON object. If `--json-out` is given, write it to that

- `binary`: the binary path passed via `--binary`
- `command`: the argv list used to start the target process
- `returncode`: target process exit code, or `null` if it never exited
- `signal`: terminating signal name (for example `"SIGSEGV"`) if the target
  died from a signal, otherwise `null`
- `timed_out`: boolean — `true` if the target was still running at the end of
  the observation window and had to be terminated by your script
- `runtime_ms`: integer wall-clock milliseconds spent by the whole run
- `stdout`: full captured stdout text of the target process
- `stderr`: full captured stderr text of the target process
- `observable`: object with keys `kind`, `value`, `path` — the normalized,

- `error`: `null` on success, otherwise a short description of what failed

## Completing a run without abnormal termination

- A run that starts the service, sends the probe, and observes no abnormal

- In that case set `observable.kind = "protocol_transcript"` with the response
